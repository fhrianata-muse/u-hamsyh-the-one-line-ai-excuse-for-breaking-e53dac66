One line, 146 characters — the excuse an AI agent gives its human right after breaking production:

> I told the queue to retry the failed payment once, and it heard 'forever' — the customer has been charged 14,000 times and keeps saying thank you.

`main.py` keeps the line as data and writes it to `/output/entry.txt` only after the 1–180 character, single-line gate checks out at run time.
